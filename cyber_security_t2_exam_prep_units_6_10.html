⚡ Master Command & Tool Cheat Sheet (Units 6–10)

Memorize these exact 1-liners to boost any descriptive answer
Tool / Concept Exact Command / Filter / Payload What It Does (1-Line Exam Answer)
Nmap Ping Sweep nmap -sn 192.168.1.0/24 Discovers live/active hosts on a subnet without scanning ports.
Nmap Stealth SYN Scan nmap -sS 192.168.1.1 Sends SYN without completing TCP handshake; evades basic IDS/firewalls.
Nmap Version / OS / Aggr. nmap -sV | nmap -O | nmap -A -sV = Service version, -O = OS & firewall detection, -A = Aggressive all-in-one.
Nmap Firewall Scans nmap -sF | nmap -sW | nmap -sA FIN scan (-sF), TCP Window size scan (-sW), ACK firewall rule mapping (-sA).
Wireshark Capture Filter tcp port 80 or ip host 192.168.1.1 Set before capture to record only specific port or host traffic.
Wireshark Display Filter http or ip.addr == 192.168.1.5 Applied after capture to filter visible packets in the Packet List Pane.
OpenVAS Setup & URL sudo apt-get install openvas && sudo openvas-setup Web UI runs on https://localhost:9392; ranks Critical, High, Medium, Low.
Domain Enumeration whois example.com | mitaka --domain example.com whois = domain owner/registrar; mitaka = subdomains & A/MX/TXT records.
DNS & Subdomain Tools dig example.com any | fierce --domain example.com Queries DNS records (A, MX, NS) and discovers subdomains/DNS flaws.
Metasploit Workflow msfconsole → search → use → set RHOSTS → run Selects an exploit, attaches a payload (e.g., Meterpreter), and compromises target.
SQLi / Cmd / XSS Payloads ' OR 1=1-- | ; ls -al | <script>...</script> SQLi targets DB; Command Injection targets OS shell; XSS targets victim's browser.
